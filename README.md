# 🏏 Vihana11 Jay Hanuman Pise — Next.js + TypeScript WebApp

Official team web application for **Vihana11 Jay Hanuman Pise**, built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

## 🚀 Quick Setup in VS Code

1. Open the `vihana11-nextjs` folder in **VS Code**.
2. Open the integrated terminal (`Ctrl + ~`) and install dependencies:
   ```bash
   npm install
   ```
3. Copy the full component code from `App.jsx` in the canvas preview into `src/app/page.tsx` (adding `"use client";` on line 1).
4. Start the local development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:3000` in your browser.

## 🌐 Free Deployment on Vercel
1. Push this folder to a GitHub repository.
2. Import the repository at [vercel.com/new](https://vercel.com/new) and click **Deploy**.
